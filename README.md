# stitchui

A modern React UI Component Library inspired by shadcn/ui.

## Features

- Modern Design
- Accessible
- Responsive
- Tailwind CSS
- JavaScript
- Vite
- Dark Mode
- Tree-shakable
- Reusable Components

## Installation

```bash
npm install
npm run dev
```

## Project Structure

```
src/
    components/
    hooks/
    utils/
    styles/
    docs/
```
