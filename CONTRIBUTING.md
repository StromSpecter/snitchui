# Contributing

Thank you for contributing.

---

# Before Coding

Search existing components.

Search utilities.

Search hooks.

Avoid duplication.

---

# Pull Request Checklist

- Builds successfully
- No lint errors
- No warnings
- Responsive
- Accessible
- Documentation updated
- Demo updated

---

# Code Style

Keep functions short.

Avoid nested conditions.

Prefer early return.

---

# Naming

Descriptive names only.

Good

```
userProfile
```

Bad

```
d
```

---

# Components

One responsibility per component.

Split large components.

---

# Styling

Tailwind only.

Use design tokens.

Never hardcode colors.

---

# Documentation

If component API changes

Update documentation.

Update demo.

---

# Commits

Use Conventional Commit.

Examples

feat(button)

fix(dialog)

docs(readme)

refactor(card)

style(input)

test(button)

chore(deps)
